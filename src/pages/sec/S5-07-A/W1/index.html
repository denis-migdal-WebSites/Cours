Consignes

Dans un premier temps, vous formerez des groupes de ~3 personnes afin de développer un challenge destiné à vos camarades. Puis, lors de la journée Challenge (6h), les différents groupes tenteront de résoudre les challenges conçus par les autres.
Les challenges seront résolus en groupes mixtes EMS/VCOD de ~6 personnes, obtenus par la fusion d'un groupe EMS avec un groupe VCOD.

Challenge

Le challenge est un exercice ludique mettant vos camarades au défi. Il devra mobiliser les connaissances et compétences acquises dans le cadre de votre formation BUT SD.
Chaque challenge doit être unique, et être d'une difficulté raisonnable. Il doit pouvoir être résolu par vos camarades sans toutefois être trop facile.

Étapes

  1. Présentation : constituez des groupes de ~3 personnes, puis choisissez un sujet que vous soumettrez à votre enseignant pour validation.
  2. Développement : créez un dépôt git privé pour votre challenge, dont vous donnerez ensuite accès à votre enseignant.
    Votre dépôt Git devra posséder un fichier contenant les membres de votre groupe, le nom de votre challenge, ainsi qu'une courte description du challenge. Vous pourrez aussi inclure une vignette illustrant votre projet.
  3. Démonstration : effectuez une démonstration de votre challenge à votre enseignant, en prenant en compte ses remarques. Bien que le challenge n'ai pas besoin d'être terminé à cette étape, il devra tout de même être suffisamment avancé afin de permettre une première démonstration.
    Votre dépôt Git devra contenir un fichier donnant les instructions nécessaires à la résolution de votre challenge, il sera transmis à vos camarades lors de la journée Challenge. Le dépôt Git devra aussi inclure un fichier décrivant la manière de résoudre votre challenge, ainsi que sa/ses solution(s).
  4. Déploiement : assurez-vous que votre challenge soit fonctionnel pour la journée de Challenge. Pour cela, vous testerez son déploiement, et corrigerez les derniers détails à finaliser. Votre dépôt Git devra contenir un fichier donnant à l'enseignant les étapes permettant de déployer votre challenge.

Conseils

  • Inspiration : consultez vos cours de 1A, 2A, et 3A pour trouver des idées de challenges.
  • Ludicité : scénarisez et/ou gamifiez votre challenge afin de le rendre plus ludique.
  • Progression : votre challenge peut comporter plusieurs étapes, chacune apportant des points.
  • Interface : ne vous focalisez pas trop sur l'interface, la priorité est d'avoir un challenge fonctionnel et substantiel.
